# نظام التحقق الذكي من الفواتير

تطبيق ويب كامل يستخدم الذكاء الاصطناعي لاستخراج بيانات الفواتير والتحقق منها ومقارنتها ببيانات شركتك.

---

## المتطلبات
- Node.js 18 أو أحدث → https://nodejs.org
- API Key من Anthropic → https://console.anthropic.com

---

## التشغيل على جهازك (محلي)

```bash
# 1. فك ضغط المجلد وادخل إليه
cd invoice-app

# 2. ثبّت المكتبات
npm install

# 3. أضف مفتاحك في ملف .env.local
# افتح الملف وضع مفتاحك بدل XXXX:
ANTHROPIC_API_KEY=sk-ant-api03-...

# 4. شغّل التطبيق
npm run dev

# 5. افتح المتصفح على
http://localhost:3000
```

---

## الرفع على Vercel (رابط إنترنت مجاني)

```bash
# 1. ثبّت Vercel CLI
npm i -g vercel

# 2. ارفع المشروع
vercel

# 3. أضف متغير البيئة من لوحة Vercel:
#    Settings → Environment Variables → أضف ANTHROPIC_API_KEY
```

أو ارفعه من الموقع مباشرة: https://vercel.com/new

---

## المميزات
- رفع صور الفواتير أو PDF أو إدخال النص
- استخراج تلقائي: الرقم الضريبي، المبلغ، التاريخ، العنوان، QR Code
- التحقق من صحة الرقم الضريبي (15 خانة)
- التحقق من احتساب الضريبة 15%
- المقارنة مع بيانات شركتك المحفوظة
- سجل كامل لجميع الفواتير المحللة مع قاعدة بيانات
- تقرير نقاط لكل فاتورة (0-100%)
